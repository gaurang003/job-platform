AI-Powered Job Platform 

AI-Powered Job Platform is a job-search and recruitment platform currently under development, designed to help candidates discover relevant job opportunities using AI-based job matching and resume analysis.
Key features being developed:
• User registration and secure authentication
• Candidate profile and resume management
• Job posting and job search functionality
• AI-based resume analysis and job matching
• Job recommendations based on skills and experience
• Application tracking system
• Recruiter and candidate dashboards
• REST APIs for communication between frontend and backend
Technologies: Java, Spring Boot, Spring Security, REST APIs, JPA/Hibernate, SQL, Git, and Spring AI, Open AI.
Status: Currently working on the project and continuously adding new features and improvements.
